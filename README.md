# 🌍 Meezan Bank International Transactions

## 📌 Overview

This dataset contains **15,000 international transactions** with details on countries, currencies, fees, risk scores, and fraud indicators. It can be used for **data analysis, fraud detection, and AML insights**.

---

## 📊 Key Features

* Transaction details (ID, type, amount)
* Countries & currencies
* Fees, taxes, and deductions
* Risk score, fraud flag, AML flag
* Channel and device used
* Sharia compliance info

---

## 🎯 Use Cases

* Exploratory Data Analysis (EDA)
* Fraud Detection
* AML Risk Analysis
* Customer Behavior Insights

---
